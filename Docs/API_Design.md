
# PrintFlow — API and JSON Contract

## Example job

{
  "jobId": "PF001",
  "customer": {
    "name": "John Banda",
    "contactNumber": "0970000000"
  },
  "jobType": "BLACK_WHITE",
  "pages": 10,
  "pricePerPage": 1.0,
  "status": "QUEUED"
}

## Rules

- jobId is unique and generated by the application.
- jobType is BLACK_WHITE or COLOUR.
- pages must be a positive integer.
- pricePerPage must be positive.
- status must be one of QUEUED, PRINTING, READY, COLLECTED.
- The application calculates the total cost; clients cannot set it directly.
- Jobs are returned in queue order.
- JSON data must survive an application restart.

## Endpoints

| Method | Path | Purpose |
|---|---|---|
| GET | /jobs | List jobs |
| POST | /jobs | Create job |
| GET | /jobs/{id}/position | Find position and status |
| PUT | /jobs/{id}/status | Change status |
| DELETE | /jobs/{id} | Cancel/remove job |
